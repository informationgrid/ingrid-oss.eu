Vielen Dank, dass Sie sich die Zeit nehmen, einen Fehler in InGrid zu melden. Ihre Mithilfe ist entscheidend, um die Qualität und Stabilität der Software zu verbessern.

## Bevor Sie beginnen

Bitte überprüfen Sie, ob der Fehler nicht bereits gemeldet wurde. Suchen Sie dazu in den [bestehenden Issues](https://github.com/search?q=org%3Ainformationgrid+&type=issues) auf GitHub. Wenn Sie den Fehler dort finden, können Sie Ihre Beobachtungen einfach zu dem vorhandenen Issue hinzufügen.

## Wie man einen guten Fehlerbericht schreibt

Je mehr Informationen Sie uns zur Verfügung stellen, desto schneller können wir das Problem identifizieren und beheben. Bitte füllen Sie die folgenden Abschnitte so detailliert wie möglich aus.

### 1. **Kurze Beschreibung des Fehlers**

* Eine oder zwei Sätze, die das Problem zusammenfassen.

### 2. **Schritte zur Reproduktion**

* Beschreiben Sie die genauen Schritte, die zum Auftreten des Fehlers führen.
* Verwenden Sie nummerierte Listen, um die Schritte klar zu strukturieren.
    1.  Schritt 1
    2.  Schritt 2
    3.  Schritt 3
* Beispiel:
    1.  Öffnen Sie den "InGridEditor".
    1.  Wechseln Sie in den Katalog XY.
    2.  Erstellen Sie einen neuen Metadatensatz.
    3.  Geben Sie unter "Titel" einen Sonderzeichen wie `ß` ein.
    4.  Speichern Sie den Metadatensatz.

### 3. **Erwartetes Verhalten**

* Beschreiben Sie, was passieren sollte, wenn Sie die Schritte aus dem vorherigen Abschnitt ausführen.

### 4. **Tatsächliches Verhalten**

* Beschreiben Sie, was stattdessen passiert ist.
* Fügen Sie, wenn möglich, Fehlermeldungen, Screenshots oder Videos hinzu. Sie können Bilder per Drag-and-Drop in das GitHub-Issue-Feld ziehen.

### 5. **Ihre Umgebung**

* **InGrid-Version:** (z.B. `1.2.3` oder `master-branch`)
* **Betriebssystem:** (z.B. `Windows 11`, `macOS 14.2`, `Ubuntu 22.04`)
* **Browser:** (z.B. `Chrome 120`, `Firefox 121`, `Safari 17.2`)
